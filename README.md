# Animal Bricks Auto

Static browser test release. Upload these files at the repository root.

Game assets are still loaded from the owner's existing easygame2021 test host.
This package does not contain the complete Unity game build. Public-host loading,
cross-origin access and mobile compatibility must be verified after deployment.

The assistant starts paused. Expand the faint arrow control and press Start.
Browser backgrounding, screen lock and sleep can interrupt gameplay.
No localhost diagnostic service or saved player screenshots are included.

For Pages, select the publishing branch and its root directory when your
account and repository support Pages. Do not upload the original work folder.
